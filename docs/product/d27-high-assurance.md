# D27 — high-assurance extraction outcome

The normal extractor remains free, local, and deterministic. When the existing
escalation key is verified, the inspector can show the agent's bounded work and
automatically sample a substantive selected source table with an actual raster
image. It sends only that table's capped PNG, matching text/hash, and existing
deterministic Markdown candidate; it never sends the key or browser state. The
model may confirm, reject, or be inconclusive—only a confirm supports the
sampled-table fidelity claim, and Markdown/offsets remain deterministic.

For Intel FY2025, cached three-turn recovery records a rejected repeated action
and then reaches the existing verifier-bound disposition batch rather than
claiming a silent success. For Duke-style filings, grouped TD headers are kept
in Markdown and repeated page-adjacent MD&A chrome is removed only when the
same group is actually present. The UI starts with boilerplate exclusion and
Markdown enabled, summarizes high-assurance state briefly, and leaves detailed
routing evidence collapsed.
