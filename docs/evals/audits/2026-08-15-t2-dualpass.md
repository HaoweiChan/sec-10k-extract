# T2 dual-pass audit — eval expansion round 1

Date: 2026-08-15. Auditors: `extraction-auditor` (methodology mode, dual-pass
duty) + `spec-drift`, run against the uncommitted T2 batch (17 cases, 11 new
fixtures, adapter/runner round 1, deploy spike). Findings condensed;
dispositions per failure-triage. A delta re-audit of the fixes is appended.

## extraction-auditor findings

1. **HIGH — five dead ASCII anchors** (jpm-2024-content ×4, msft-2013-content
   ×1): fixtures encode `&#8211;`/`&#8217;`/`&#146;`; the anchors used ASCII
   `-`/`'`, verified only by a silently-transliterating scratch renderer.
   → Disposed: ADR-003 gained a normalization canon (entities → real Unicode,
   no transliteration; whitespace collapse also after decoding); all five
   anchors rewritten to canon and re-counted.
2. **HIGH — ADR-004 misdescribed Textron** as an internal-pointer example;
   the fixture's pointers name the external 2001 Annual Report exhibit.
   → Disposed: ADR-004 amended (Textron = shape 1; the audit is cited in the
   ADR).
3. **MED-HIGH — Textron Items 10/5 pins used an unratified tie-break** and
   Item 5 (substantive content + pointer) was mis-pinned IBR.
   → Disposed: ADR-004 pointer-only-mixed rule added; Item 5 re-pinned
   `extracted`; provenance now cites the ADR.
4. **MED — text checks on null-offset items scanned the whole document**
   (`normalized_text[None:None]`). → Disposed: adapter status guards +
   self-check test.
5. **MED — `deterministic` compared full dicts incl. `timings`** — an
   invariant-tagged check no honest pipeline could pass. → Disposed: compares
   `normalized_text`/`items`/`doc_status`/`warnings` only.
6. **MED — `omitted`/`missing` unreachable under the cases' convention**,
   contradicting architecture layer 7 and the premier-pacific stratum label.
   → Disposed: **ADR-005** (heading present → `extracted` however trivial;
   `omitted` = era-permitted absent heading; `missing` = expected absent
   heading); layer 7 rewritten; stratum relabeled "SRC 7A-relief".
7. **LOW-MED — jpm glossary anchor count claim wrong** (1 vs 9).
   → Disposed: provenance corrected; `max_chars` still guards the anchor.
8. **LOW — msft anchor straddles a raw source newline**. → Disposed: covered
   by the canon's whitespace-collapse rule; noted in provenance.
9. **LOW — GE "101×" was a `grep -c` line count** (true count 102).
   → Disposed: corrected.
10. **LOW — no case demanded exact `doc_status: "success"`** (a
    gratuitous-warning pipeline was never penalized). → Disposed:
    nvda-2024-shallow pins exact success.

Verified clean on first pass: all 13 fixture byte sizes; malformed-html's
three mutations byte-for-byte; the 10-Q's dei tags; expected sets vs heading
scans for all 11 new fixtures (incl. the genuine CAT "Item 1D" trap and the

in-span position; JPM item-7/8 pointer lengths (395/370 chars).

### Final disposition (Item 16)

ADR-005 stands: reporting `16: omitted` is exactly the "not in filing" vs
"extractor missed it" distinction INV-S4 exists for. The post-2016 cases were
fixed to enforce it — jpm-2024-structure asserts `item_present 16
status omitted` (16 joins its expected/allowed lists), sandston-2021 and
premier-pacific-2016 likewise, malformed-html's whitelist admits 16;
pre-2016 cases keep their exclusions (16 not era-valid). This closes the
last open finding of the T2 audit cycle.
