# D30 — multi-model policy decision

## Material request

Specialize the LangGraph recovery roles: use Flash for one bounded evidence
pass and Pro for compact planning/re-planning, while deterministic code retains
all offset/hash binding, verification and publication authority.

## Outcome

The implementation records both model ids, response-shape/reasoning caps,
cache-key isolation, Flash's public catalogue price, and semantic disposition
binding. The production graph runs one bounded Flash evidence node before up to
three Pro planner turns, while each document retains a $0.10 cap even with a
shared process budget. Offline evaluation uses neither an LLM access key nor
provider calls; its cached route also proves that untrusted filing text and
extra output fields cannot alter the role policy or publish offsets.
