[`tasks/DONE.md`](DONE.md) per [ADR-022](../specs/decisions/ADR-022-done-split.md)

gate stays here regardless of age (T3–T5 today) — the split changes where a
settled row is filed, never whether a gate must be observable.

any subset can run as parallel pr-loop sessions. (T3–T5's outstanding work is
their own UNRUN gates, not another milestone.)

after it is evidence-deepening only — `docs/product/milestones.md` ranks the
A-backlog. A new capability after the freeze is scope creep no matter how good

  makes the first half safe. Unvalidated offsets were the worst option: IBR

  disowned 4,805 chars in silence.
